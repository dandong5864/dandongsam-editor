# 상품 판매형 쇼핑쇼츠

소비자의 불편 → 해결 방법 → 제품 특징 → 구매 유도 순서로 짧게 보여 준다. 공통 흐름은 `../SKILL.md`를 따른다.

## 대본
- 첫 3초: 많은 사람이 겪는 불편을 한 문장으로. 예) "욕실 물때, 매번 박박 문지르시죠?"
- 특징은 영상에서 보이는 것 2~3개만. 성능 숫자·인증은 사용자가 준 자료에 있을 때만 쓴다.
- 마지막은 부드럽게: "자세한 건 설명란에 있어요." 같은 말. 과장 표현은 쓰지 않는다.
- 20~40초 안팎. `결과/대본.txt`에 저장한다.

## 편집
- 사용 장면 → 결과 장면을 붙여서 보여 준다. 제품 이름·가격 글자는 사용자가 준 정보만 넣는다.

## 결과물
- `.dsp`, `결과/대본.txt`, `결과/업로드.txt`(제목 후보, 설명, 해시태그, "광고 포함" 같은 표시가 필요한지 확인하라는 메모, 링크 자리 "[링크]").
