# 생활 꿀팁 쇼츠

살림·주방·청소·수납 영상을 보고 "따라 하고 싶은" 짧은 쇼츠를 만든다. 공통 흐름은 `../SKILL.md`를 따르고, 아래만 더한다.

## 기획
- 영상에서 실제로 보이는 꿀팁만 쓴다. 영상에 없는 효과·숫자를 지어내지 않는다.
- 꿀팁이 여러 개면 가장 놀라운 것 하나를 맨 앞에 둔다.

## 대본
- 첫 3초 후킹: 문제를 짧게 던진다. 예) "냄비 탄 자국, 이걸로 1분이면 끝나요."
- 한 문장은 짧게(자막 한 줄에 들어가게). 순서는 문제 → 준비물 → 방법 → 결과 → 한마디.
- 전체 길이는 20~45초 안팎. 대본은 `결과/대본.txt`에도 저장한다.

## 편집
- 손동작이 보이는 장면은 자르지 않는다. 기다리는 장면(물 끓이기 등)은 짧게 자른다.
- 결과가 보이는 장면(전/후)은 1초 이상 보여 준다.
- 효과음은 결과가 보이는 순간에 한 번 정도만.

## 결과물
- `.dsp`, `결과/업로드.txt`(제목 3개 후보, 설명 2~3줄, 해시태그 5개 안팎).
