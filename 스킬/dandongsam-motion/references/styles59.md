# 참고 스타일 59개 (HTML 로 직접 그릴 때)

편집기에 기본으로 들어 있는 스타일은 6개뿐이다(howto, lineicon, newsshorts, pptpen, cardnews, broadcast). 아래 표는 **HTML 로 직접 그릴 때**(Codex·Claude Code) 참고하는 목록이다. 한 줄 설명만 있으니, 사용자가 "그코키트 스타일 블록"을 붙여 넣었다면 그 블록의 색·글꼴·그리기 코드를 우선한다.

- 색은 앞에서부터 배경 → 글자·선 → 강조 순서.
- 글꼴은 편집기 안에서 비슷한 무료 글꼴로 바뀐다: 고딕·본문(Noto Sans KR 등) → Do Hyeon, 굵은 제목(Black Han Sans·Jua·Bagel 등) → Black Han Sans, 명조(Noto Serif KR·Song Myung 등) → NanumMyeongjo Bold, 손글씨(Nanum Pen Script·Gaegu 등) → Kyobo Handwriting 2019. 영어 고정폭(IBM Plex Mono)은 기본 고정폭 글꼴로 보인다.
- **실사 연결**은 촬영·AI 영상과 이어 붙이기 쉬운 정도: ◎ 아주 쉬움(어두운 배경) / ○ 보통 / △ 대비가 큼.

### 추천할 때 빠르게 고르는 법
- **촬영·AI 영상이 어둡고 영화 같음(밤·기내·우주·사건):** network, lineicon, darktech, glass, globe, space, mystery, geomap, blueprint
- **촬영·AI 영상이 밝은 일상(집·가게·요리):** flat, howto, fintech3d, dashboard, cardnews, studynote
- **숫자·비교가 핵심:** stockchart, dashboard, ranking, picto, darktech
- **구조·과정:** diagram, blueprint, isometric, circuit, flowchart, network
- **한국 역사·전통:** hanji, minhwa, newspaper
- **감정·여운으로 끝나는 이야기:** sunset, watercolor, lofi
- 3개 추천은 성격이 다르게: "가장 자연스러운 것 1 + 더 또렷한 것 1 + 의외의 선택 1".
- **화면 뼈대가 겹치지 않게 고른다.** 추천 3개는 아래 뼈대 묶음에서 **서로 다른 묶음 3개**에서 하나씩 고른다(같은 묶음에서 두 개 금지). 분류(강의·쇼츠·테크·감성)도 최소 2개에 걸치게 한다.
  - 어두운 배경 + 빛나는 선: lineicon, network, circuit, darktech, globe, glass
  - 손그림·필기: doodle, whiteboard, chalk, studynote, pptpen
  - 카드·격자: cardnews, flashcard, dashboard, howto, newsshorts, broadcast
  - 글자가 주인공: kinetic, variety, terminal
  - 게임·퀴즈: quiz, ranking, pixel
  - 입체·물건: isometric, blocks, clay, popup, fintech3d
  - 도면·단면·실험: blueprint, diagram, lab, mathstep
  - 캐릭터·이야기: chat, vivid, puppet, webtoon, analogy
  - 통계·차트: picto, stockchart, mindmap, flowchart
  - 시네마틱 풍경: sunset, space, neon, geomap, mystery, lofi
  - 질감·레트로: vhs, y2k, newspaper, scrapbook, hanji, minhwa, watercolor, bmovie, appdemo, aichat, flat
- **세 가지 축에서 다르게:** 색 분위기(어둠/밝음/질감), 움직임 성격(차분한 그려짐/통통 튀는 등장/글자 리듬), 정보 전달 방식(도식·비유/카드·숫자/캐릭터·이야기) 중 최소 두 축이 세 추천마다 달라야 한다. 실사 연결(◎)만으로 세 개를 고르지 않는다. 밝은 스타일도 쓸 수 있다.
