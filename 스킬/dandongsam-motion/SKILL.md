# 단동샘 모션그래픽

모션그래픽 영상을 **직접 만들지 않는다.** `.dsp`에 "설계도"(`mg`)만 적으면 단동샘 편집기가 열 때 그 설계도로 영상을 그려(HTML Canvas → ffmpeg) "추가 미디어" 줄 또는 영상 줄에 올리고, 작업 폴더의 `결과/모션그래픽/`에도 저장한다. 사용자는 편집기에서 위치·길이를 바꾸거나, 지우거나, 글자·모양을 고쳐 다시 만들거나, 다른 영상으로 바꿀 수 있다.

이하 `SKILL_DIR`은 이 SKILL.md가 있는 폴더다. 작업 폴더에서는 보통 `모션그래픽스킬/`이고, 컷 편집·받아 적기·AI 목소리 도구는 옆의 `단동샘스킬/`(쇼츠 컷편집 스킬)에 있다.

## 지켜야 할 것

1. 유료 AI 영상·이미지 생성 서비스를 쓰지 않는다. 실사·AI 영상·사진은 **작업 폴더에 사용자가 넣어 둔 파일만** 쓴다.
2. 원본 영상·내레이션은 이름도 내용도 바꾸지 않는다. 모션그래픽 mp4 를 직접 만들지 않는다(편집기가 만든다).
3. `편집설정.json`과 `편집파일_만드는법.txt`의 [모션그래픽] 규격을 따른다. 사용자가 말한 값이 가장 우선이다.
4. 지어낸 숫자·통계·규정을 넣지 않는다. 대본·내레이션에 나온 숫자만 쓰고, 예시 숫자면 `[예시]`라고 적는다. 실제 회사 로고·캐릭터는 그리지 않는다.
5. 끝나면 `python SKILL_DIR/scripts/check_motion.py "<.dsp>"`로 검사하고, 고친 뒤 보고한다.

## 제작 모드 (편집설정.json 의 `motion.mode`)

| mode | 뜻 | 영상 줄(clips) | 모션그래픽 |
|---|---|---|---|
| (motion 이 null) | 일반 자동 편집 | 원본 컷 편집 | 넣지 않는다 |
| `mix` | 촬영 영상 + 모션그래픽 | 원본 컷 편집 그대로 | `texts`에 `kind:"mg"`로 필요한 곳만 덮는다(내레이션은 계속) |
| `only` | 모션그래픽 전용 | 모든 장면이 `{"mg":{...},"dur":초}` 조각 | 내레이션 문장마다 장면 하나 |
| `multi` | 실사·AI 영상·사진·모션 복합 | 폴더의 영상·사진 조각과 mg 조각을 섞어 이어 붙임 | 장면(실사) → 원리(모션) → 장면 흐름 |

- `only`·`multi`는 내레이션이 기준이다. 내레이션 파일이 있으면 그것을, `voice`가 있으면 `단동샘스킬/SKILL.md`의 "AI 목소리"로 만든 `내레이션.mp3`를 `audio`에 넣는다. 둘 다 없으면 대본만 `결과/대본.txt`로 저장하고 멈춰서 알린다.
- `multi`에서 사진은 `media`에 파일 이름으로 넣고 조각 길이를 `in 0, out <초>`로 적는다(편집기가 사진을 정지 영상으로 쓴다). 영상이 모자라면 그 자리를 모션그래픽으로 채우고, 새로 만들어 달라는 말은 하지 않는다.
- 사용자가 "모션그래픽만 만들어 줘"처럼 이 스킬만 부르면 `편집설정.json`이 없어도 `only`로 보고, 화면 모양은 사용자 말 → 없으면 9:16.

## 1. 내용 파악

1. 받아 적은 단어 시각을 쓴다: `받아적기/<파일>.words.json`이 있으면 그것, 없으면 `python 단동샘스킬/scripts/transcribe.py "<파일>" --out "<임시폴더>/words.json"`. 둘 다 안 되면 자막·모션 시각을 짐작하지 말고 알린다.
2. `mix`면 먼저 `단동샘스킬/SKILL.md` 순서대로 컷 편집(무음·군말·반복 정리, `repeats.py`)과 자막을 끝낸 뒤, **완성 영상 시각**으로 모션그래픽 자리를 정한다.
3. 문장마다 아래 표로 "모션그래픽이 필요한 말"인지 판단한다. 말만으로도 충분한 문장, 화면을 보며 따라 해야 하는 장면(클릭·결과 화면)은 덮지 않는다.

| 들리는 말 | 모양(type) | 화면에 쓰는 것 |
|---|---|---|
| 첫째·둘째, 먼저→다음→마지막, 단계 | `steps` | 단계 2~5개, 한 줄 14자 안팎 |
| 가격·%·배·개수 같은 숫자 하나가 핵심 | `number` | 숫자(`value`)와 짧은 설명(`label`) |
| A와 B, 전과 후, 장점과 단점, ~보다 | `compare` | 양쪽 이름·숫자·한 줄 설명, 나은 쪽 `win` |
| ~하면 ~가 되고 ~해서, 원리, 과정, 구조 | `flow` | 단계 2~5개를 화살표로 |
| 결론, 꼭 기억할 말, 반전, 첫 2초 후킹 | `quote` | 한 문장, 강조어만 `[ ]` |
| 준비물, 챙길 것, 주의할 것 목록 | `list` | 항목 2~6개 |

## 2. 얼마나, 어디에 (비중 `motion.amount`)

- `low` 1분에 1~2개, `mid` 2~3개(기본), `high` 4~5개. `only`는 내레이션 전체를 모션그래픽 장면으로 채운다.
- 한 모션그래픽은 그 말을 하는 동안만 보여 준다: 3~8초. 말 시작 0.2초 전에 시작해 말이 끝나고 0.5초 뒤에 끝낸다.
- 항목이 하나씩 나오는 모양(steps·flow·list)은 `at`에 항목을 말하는 시각(그 모션그래픽 시작부터 초)을 적어 내레이션과 맞춘다.
- **같은 모양을 연달아 쓰지 않는다. 같은 내용을 두 번 보여 주지 않는다.** 모션그래픽끼리 시간이 겹치지 않게 한다.
- 모션그래픽이 나오는 동안에도 내레이션은 그대로 이어진다(`mix`의 `kind:"mg"`는 영상 위에 덮는 것이라 소리를 건드리지 않는다). 영상 조각을 자르거나 늘려 내레이션을 끊지 않는다.

## 3. 스타일 (`motion.style`)

편집기 기본 스타일 6개:

| style | 이름 | 어울리는 영상 |
|---|---|---|
| `howto` | 단계별 따라하기 (밝은 베이지·번호 카드·진행 막대) | 요리·청소·사용법, 생활 꿀팁 |
| `lineicon` | 라인 아이콘 (검정·흰 선·지금 말하는 것만 연두) | AI·개념·업무 흐름, 작동 원리 |
| `newsshorts` | 뉴스 카드 (검정·노랑 제목 띠·큰 숫자) | 이슈·바뀐 제도·가격, 쇼츠 후킹 |
| `pptpen` | 인강 PPT 첨삭 (흰 슬라이드·남색 머리띠·빨간 펜) | 강의·업무 교육 |
| `cardnews` | 카드뉴스 (연보라·둥근 파스텔 카드) | 생활 꿀팁·체크리스트 |
| `broadcast` | 방송 뉴스 그래픽 (남색 데이터 판) | 정책·통계·사건 경과, 비교 |

- `motion.style`이 `auto`가 아니면 모든 모션그래픽에 그 스타일을 쓴다.
- `auto`면 영상 성격으로 **1~2개만** 골라 통일한다: 강의 → `pptpen`, 생활 꿀팁 → `howto`·`cardnews`, 상품·가격 → `newsshorts`, 원리·기술 → `lineicon`, 정책·통계 → `broadcast`. 촬영 영상이 어두우면 어두운 스타일(`lineicon`·`newsshorts`·`broadcast`), 밝으면 밝은 스타일.
- 사용자가 다른 스타일 이름(예: 그코키트 59개 중 하나)을 말하면 `references/styles59.md`를 보고 가장 가까운 기본 스타일을 고르거나, 파일을 만들 수 있는 AI라면 아래 "직접 그린 HTML"로 그 스타일을 그린다.

## 4. .dsp 에 적기

규격은 작업 폴더의 `편집파일_만드는법.txt` [모션그래픽]. 핵심만:

```json
{"id":"g1","kind":"mg","start":12.3,"end":17.0,
 "mg":{"type":"steps","style":"howto","title":"김치찌개 끓이는 순서","items":["고기 먼저 [달달] 볶기","김치 넣고 5분","물 붓고 20분"],"at":[0.5,1.8,3.2]}}
```

- 촬영 영상 위(`mix`): `texts`에 위 모양. 바탕을 비우고 영상 위에 겹치려면 `"clear": true`(숫자 하나·핵심 문장처럼 짧은 것에만).
- 모션그래픽 장면(`only`·`multi`): `clips`에 `{"id":"c3","mg":{...},"dur":4.5}`. `mediaId`·`in`·`out`은 쓰지 않는다. 영상 조각 합계가 내레이션 길이와 같게(±0.3초).
- 화면 글자: 제목 14자 안팎, 항목 14자 안팎, 큰 수는 한국식(1만 2천 원). 강조할 말 1~2개만 `[ ]`.
- 화면 아래 22%는 자막 자리라 편집기가 비워 두고 그린다. 쇼츠 색 띠(tpl)가 있으면 편집기가 가운데 칸에 맞춰 그린다. 화면 비율(16:9·9:16·1:1)은 `canvas`를 따른다. 원본 영상은 자르거나 늘이지 않는다(`fit: contain`).
- 제목·자막·효과음·템플릿 설정은 원래 규칙 그대로 둔다. 모션그래픽 때문에 자막을 빼거나 옮기지 않는다.

### 직접 그린 HTML (선택: Codex·Claude Code 처럼 파일을 만들 수 있을 때만)

기본 모양으로 표현하기 어려운 장면(구조 단면, 지도, 특별한 비유)만 HTML 로 그린다. ChatGPT 는 쓰지 않는다.

- `결과/모션그래픽/장면1.html`에 `<canvas id="c" width="1920" height="1080">`(세로는 1080×1920)와 `window.draw(t)`(t=초, 같은 t면 같은 그림을 그리는 순수 함수), `window.DUR`(초)을 둔다. `window.__RENDER__`가 true 면 자체 재생 루프를 돌리지 않는다. 화면 크기는 `window.W`, `window.H`.
- 인터넷은 막혀 있다(글꼴·그림·스크립트 주소 모두 안 됨). 글꼴은 `"Black Han Sans"`(제목), `"Do Hyeon"`(본문)을 이름으로 쓴다. 난수는 고정 시드.
- 시작 0.45초는 배경색에서 밝아지고 끝 0.4초는 배경색으로 어두워지게. 15초에 눈에 띄는 변화 6~9번. 세로 영상은 아래 20%·오른쪽 12%를 비운다.
- `.dsp`에는 `{"mg":{"html":"모션그래픽/장면1.html"}}`로 적는다(`texts`·`clips` 둘 다 가능).

## 5. 검사와 보고

```
python SKILL_DIR/scripts/check_motion.py "<작업 폴더>/결과/<이름>.dsp"
python 단동샘스킬/scripts/validate_dsp.py "<작업 폴더>/결과/<이름>.dsp"
```

- 오류(✗)는 모두 고친다. 경고(!)는 이유가 있으면 남기고 보고에 적는다.
- 보고(한국어, 짧게): 만든 .dsp 경로, 제작 모드·스타일·비중, 모션그래픽 목록(시각·모양·화면 글자), 넣지 않은 이유가 있는 곳, 확인하지 못한 것. 편집기에서 처음 열 때 모션그래픽을 그리느라 시간이 걸린다고 알린다.
