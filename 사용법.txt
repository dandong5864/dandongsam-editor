단동샘 편집기 — 쉬운 무료 로컬 영상 편집기
=========================================

[시작하기]
 1) 시작하기.bat 더블클릭 (처음 한 번은 구성요소를 내려받느라 1~2분 걸려요)
 2) 편집 창이 자동으로 열립니다. 영상을 창에 끌어다 놓으면 끝!
 3) 매번 폴더를 열기 번거로우면 [바탕화면에_아이콘_만들기.vbs] 을 한 번 실행하세요.
 ※ 검은 콘솔 창은 최소화만 해 두세요. 닫으면 프로그램이 종료됩니다.

[기본 흐름]
 영상 끌어다 놓기 → Space로 재생 → 자를 곳에서 Ctrl+B → 필요 없는 조각 클릭 후 Delete
 → Ctrl+E 로 내보내기

[샘플 쇼츠를 직접 고쳐 보기]
 위쪽 [📂 샘플 열기] (또는 빈 화면의 파란 버튼)을 누르면 제가 만든 쇼츠가 그대로 열려요.
 - 아래 [💬 자막] 줄의 파란 막대를 누르면 오른쪽에서 문구·색·크기·위치를 고칠 수 있어요.
 - [🅣 텍스트] 줄의 주황 막대가 위쪽 두 줄 제목이에요 (줄마다 색이 달라요).
 - 화면 속 글자를 마우스로 끌면 위치가 바뀌고, 막대를 끌면 나오는 시간이 바뀌어요.
 - 영상 클립을 누르면 '잘라내기'로 1:1 / 4:5 / 9:16 크롭과 좌우 위치를 바꿀 수 있어요.
 - 아무것도 선택 안 했을 때 오른쪽에서 배경을 '검정 / 흐리게(블러)'로 바꿀 수 있어요.

[템플릿 (색 띠 배경)]
 - 아무것도 선택 안 한 상태에서 오른쪽 '배경' → [템플릿 (색 띠)]를 누르세요.
 - 위쪽 칸·아래쪽 칸 높이(%)와 위/가운데/아래 색을 마음대로 바꿀 수 있어요.
 - [영상을 가운데 칸 안에]를 고르면 영상이 가운데 칸에만 들어가고, 위·아래 칸은 제목·자막 자리로 쓸 수 있어요.

[효과음 폴더]
 - 쇼츠 효과음 87개가 이미 편집기 안(효과음 폴더)에 들어 있어요. 왼쪽 [오디오] 탭에 ⭐ 표시로 바로 나와요.
 - 왼쪽 [오디오] 탭에서 D:\클래스유 자료\쇼츠 효과음 폴더의 소리 목록이 나와요.
 - [▶ 듣기]로 미리 듣고, [＋ 추가]를 누르면 재생 막대 위치의 '추가 소리' 줄에 들어가요 (끌어서 위치 조절).
 - 폴더가 다르면 칸에 경로를 붙여넣고 [폴더 바꾸기]. 하위 폴더 안의 파일도 보여요. 원본은 건드리지 않아요.

[글자·폰트]
 - 왼쪽 [텍스트] 탭의 ＋ 기본 텍스트(제목용), [자막] 탭의 ＋ 자막 추가(자막용) — 재생 막대 위치에 새로 생겨요.
 - 글꼴 목록에는 카페24 폰트 6종이 들어 있어요.
 - [＋ 내 폰트 추가]로 컴퓨터의 .ttf / .otf 파일을 고르면 목록에 추가돼요 (workspace\fonts 에 저장, 다음에도 유지).
 - 내보내기 때 글자도 영상에 같이 들어가요. '소리 크기 자동 맞춤'을 켜면 목소리 크기가 고르게 맞춰져요.

 Ctrl+C / Ctrl+V  복사 / 붙여넣기
 Ctrl+Alt+C / V   특성 복사 / 붙여넣기 (크기·위치·폰트 등 스타일만 복사)

 Ctrl+. / Ctrl+,  음량 올리기 / 내리기

 Ctrl+E           내보내기
 ?                단축키 목록 보기

[할 수 있는 것]
 - 영상/오디오 여러 개 가져오기 (끌어다 놓기, mp4·mov·mkv·avi 등 대부분 가능)
 - 컷 자르기·삭제·순서 바꾸기(클립을 끌어서 이동)·양 끝 손잡이로 길이 조절
 - 구간 시작/끝을 숫자로 입력
 - 클립별 음량(0~200%)·음소거·속도(0.25~4배)
 - 화면 비율(원본/16:9/9:16/1:1/4:3), 확대, 위치 이동, 90도 회전, 좌우 반전, 채우기
 - 추가 소리(배경음악·효과음) 트랙: 끌어서 위치 이동, 자석 정렬
 - 소리 파형 표시
 - 글자(제목·자막) 넣기, 폰트 추가·선택, 크롭, 배경 블러
 - 모션그래픽(단계·숫자·비교·흐름·핵심 문장·목록) 넣기: 왼쪽 [효과] 탭. 겹친 영상 줄에 올라가 옮기기·길이·삭제·바꾸기·글자 고치기 가능
 - AI 자동 편집에서 제작 모드(일반/모션그래픽만/촬영+모션/복합)·모션 스타일·비중 고르기. 만든 모션그래픽은 작업 폴더 결과\모션그래픽\ 에도 저장
 - MP4 / MP3 / WAV 내보내기, 현재 장면 PNG 캡처
 - 작업 내용 자동 저장 (창을 닫았다 다시 열어도 이어서 작업)

[폴더]
 다운로드\단동샘 편집기\내보내기\   완성된 영상이 저장되는 곳
 다운로드\단동샘 편집기\캡처\       Ctrl+P 로 찍은 장면이 저장되는 곳
 다운로드\단동샘 편집기\자동편집\   AI 자동 편집 작업 폴더
 workspace\  가져온 파일 사본 (용량이 커지면 미디어 목록에서 ✕ 로 지우세요)

[참고]
 - 원본 파일은 건드리지 않습니다. 가져올 때 workspace 폴더로 복사해서 사용해요.
 - 컴퓨터 안에서만 동작하며 인터넷으로 영상이 전송되지 않습니다.

[스티커 (이미지·GIF)]
 - 왼쪽 [스티커] 탭 → [＋ 이미지 / GIF 추가]로 내 컴퓨터의 PNG·JPG·GIF·WEBP 파일을 불러와요.
 - 목록의 그림을 누르면 재생 막대 위치에 3초 동안 들어가요. 화면에서 끌어서 옮기고, 오른쪽에서 크기·회전·시간을 바꿔요.
 - 움직이는 GIF는 나오는 동안 계속 반복돼요. 지우려면 선택하고 Delete.
 - 불러온 파일은 편집기 폴더의 [스티커] 폴더에 저장돼요.

[프로젝트 저장 / 열기]
 - 위쪽 [💾 저장] (Ctrl+S): 지금 작업을 이름 붙여 저장해요. 한 번 저장하면 다음부터는 같은 이름에 덮어써요.
 - [📁 프로젝트]: 저장한 프로젝트 목록에서 [열기] / [삭제], 새 이름으로 저장할 수 있어요.
 - [📤 파일로 내보내기]: 편집 내용을 .dsp 파일 하나로 저장해요 (백업·옮기기용). [📥 파일 열기]로 다시 불러와요.
 - .dsp 파일에는 편집 내용만 들어 있어요. 다른 컴퓨터에서 열 때는 같은 영상 파일을 [미디어]에 먼저 가져오면 이름으로 자동 연결돼요.
 - [새 프로젝트]는 화면만 비우고, 저장해 둔 프로젝트는 그대로 남아요.

[칸 크기 조절]
 - 왼쪽 패널 / 가운데 화면 / 오른쪽 패널 사이의 세로 경계선, 화면과 타임라인 사이의 가로 경계선을 마우스로 끌면 크기가 바뀌어요.
 - 경계선을 더블클릭하면 원래 크기로 돌아와요. 바꾼 크기는 기억해요.

[클립 순서 바꾸기]
 - 영상 클립을 끌면 들어 올려져서 따라와요. 원래 자리는 점선 빈칸으로 남고, 하늘색 세로선이 들어갈 위치를 알려줘요. 놓으면 그 자리로 들어가요.
 - 선택한 클립은 흰색 테두리로 표시돼요.

[마그넷 · 자동 스냅] (타임라인 오른쪽 위 버튼, 눌러서 켜고 끄기)
 - 🧲 마그넷: 영상 클립을 지우거나 길이를 줄이면, 그 뒤에 있는 자막·텍스트·스티커·소리도 같이 당겨져요.
   영상 클립 순서를 바꿀 때도, 그 클립에서 시작하던 자막·텍스트·스티커·소리가 클립을 따라 같이 이동해요.
 - 🧲 자동 스냅: 자막·텍스트·스티커·소리를 끌 때 다른 클립의 끝, 재생 막대, 시작점에 착 붙어요. 붙을 때 흰 세로선이 보여요.

[색 고르기]
 - 글자색, 테두리 색, 색 띠 템플릿(위·가운데·아래) 모두 같은 색 판이 나와요. 첫 칸은 직접 고르기, 나머지는 기본 색이에요.
 - [내 색]에서 [＋ 지금 색 저장]을 누르면 지금 색이 저장돼요. 칸 모서리의 ×를 누르면 지워져요.

[숫자 직접 입력]
 - 음량, 속도, 크기, 위치 같은 슬라이더 오른쪽 숫자를 누르면 직접 입력할 수 있어요. 숫자를 쓰고 Enter (↑↓ 키로 1씩, Shift+↑↓ 로 10씩). 범위를 넘으면 가장 가까운 값으로 맞춰져요.

[색 띠 템플릿]
 - 영상은 화면 가운데에 고정되고, 위·아래 색 띠는 그 뒤 배경으로 깔려요. 띠 높이를 바꿔도 영상은 움직이지 않아요.

[효과음 파일 추가]
 - 왼쪽 [오디오] 탭 맨 위의 [＋ 내 컴퓨터에서 효과음 파일 추가]를 눌러 mp3·wav·m4a 파일을 고르면 편집기 안에 저장돼요. 따로 폴더를 지정할 필요는 없어요.
